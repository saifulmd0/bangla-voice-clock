# Privacy policy

**Bangla Voice Clock** (বাংলা ভয়েস ক্লক), by Saiful Islam. Last updated 23 October 2026.

Bangla Voice Clock does not collect, store or share personal information.

- **No accounts, ads, analytics or tracking.** The app has none of these.
- **Your settings stay on your computer.** They are saved in a file in your user folder and are
  never sent anywhere. So is the app's error log, which only you can read.
- **The voices are built in.** Announcements are made from recordings that ship with the app, so
  nothing you hear is fetched over the internet.
- **The update check.** Copies downloaded from GitHub ask GitHub once a day for the list of
  releases, so they can tell you about a new version. GitHub sees the app's version and your IP
  address, as with any web request; nothing else is sent. GitHub's own privacy statement covers
  that request. The Microsoft Store and Flathub copies don't check: their stores update them, and
  they make no network requests of their own.
- **Children.** The app collects nothing from anyone, children included.

If this policy changes, the new version will be published here with a new date.

Questions: [open an issue](https://github.com/saifulmd0/bangla-voice-clock/issues).
